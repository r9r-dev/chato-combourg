# Game Rules

Game is a 3x3 cards with two extra resources :
- Keys
- Coins

Total score is : sum of each card points + keys (one key = one extra point).

## Individual card

Each card has it's own points that must provided to player to let him verify how it's calculated. Score details must also be provided.

Each card has an id from 001 to 092 with provided rules. Everytime a row, a column or any other rule specifies quantity to score, the current card is also counted in the score.

For example, 001 scores 4 for each blue shield on the same column. 001 already has a blue shield, so it already score 4 points.

When a card tell "for each coin on this card", coins are taken from player extra resources, used on the card and can't be further moved to another card.
