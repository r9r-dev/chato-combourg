# Pour toutes les cartes qui possèdent un cadenas
- Placer une clé depuis la réserve sur cette carte.
En dépensant la clé, [EFFET CADENAS] s'applique.

# Note sur les cartes retournées
Les cartes retournées ne sont ni du château, ni du village.

# Message
Les cartes avec un [M] possèdent l'icône messager.

# OU
Quand il est écrit [OU]. Le joueur choisi un effet ou l'autre mais pas les deux.

# Chez un de vos voisins
Si on vous propose un effet en fonction d'un de vos voisins, choissez toujours le plus avantageux pour vous.
